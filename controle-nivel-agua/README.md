# 🚰 SVNAR - Sistema de Verificação do Nível da Água do Reservatório 

## 🎯 Objetivo
O sistema criado tem como objetivo monitorar e exibir mensagens de alerta com cores diferentes, conforme o nível de água do reservatório.

## 👩‍💻 Como utilizar o sistema? 
- Primeiro, execute o sistema;
- Segundo, aperte a tecla `enter` para iniciar o monitoramento;
- Terceiro, caso queira encerrar o monitoramento, aperte `ctrl+c`.

## ⚙️ Como o sistema funciona? 
O sistema irá monitorar o nível de água dentro do reservatório e irá exibir um alerta específico para cada nível, podendo ser:
| **Nível do Reservatório** | **Mensagem** |
| --- | --- |
| Nível 1 | Muito baixo (crítico) |
| Nível 2 | Baixo |
| Nível 3 | Médio |
| Nível 4 | Alto |
| Nível 5 | Muito alto (alerta) |

Após identificar o nível de água dentro do reservatório, o sistema irá refazer essa verificação novamente, repetindo o processo à cada 5 segundos.
